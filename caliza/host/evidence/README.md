# Estratos host-render evidence

These PNGs were rendered by the scripted host preview from the executable UI model/renderer, not copied from the concept images. Regenerate them with:

```sh
bash caliza/host/build-host.sh
bash caliza/host/capture-estratos.sh
```

The harness uses fictional games and procedural cover art. It is host evidence only; real PS4 presentation, controller input and VM compositing require hardware validation.
