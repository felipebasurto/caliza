# PS4 / PS5 Homebrew PS2 Emulator Technical Comparison

This document compares the source code of active PS4 and PS5 homebrew PlayStation 2 emulators, Play!, upstream PCSX2, and public PSDevWiki configuration taxonomy against Caliza `main` (post-PR #9, commit `b2d29b4`). Every finding is verified directly against cloned source trees and commit histories, classified by accuracy impact and license compatibility, and assigned an engineering verdict (`adopt`, `adopt as option`, or `skip`).

## 2. Priority-Ordered Top Findings

1. **EE `recPLZCW` branchless `LZCNT` (Forja SX2, app 173)** — Accuracy-preserving. Replaces two data-dependent branches per 32-bit half of PS2 `PLZCW` with `mov/sar/xor/lzcnt/dec`. AMD Jaguar (`btver2`) supports ABM/`LZCNT` natively. Bit-exact across all \(2^{32}\) inputs. **Verdict: Adopt (implemented).**
2. **EE VTLB constant-address load/store scratch `push`/`pop` elision (Swordpdf/PS5SX2, `cd3da52`)** — Accuracy-preserving. Caliza already avoids `push`/`pop` on SIB-safe GPR reads, but still emits dead `push`/`pop` of `rax`/`rcx` on every constant-address store, XMM load, and SIB-unsafe GPR load (`rsp`/`rbp`/`r12`/`r13`). Swordpdf measured 6%–27% of hot EE block instructions spent on those `push`/`pop` pairs. **Verdict: Adopt (implemented).**
3. **microVU1 register-cached VU memory base (Forja SX2, app 158)** — Accuracy-preserving. Because PS4 VU1 data memory resides above 4 GiB, `xComplexAddress` emits a 10-byte `movabs` on every `LQ`/`SQ`/`LQI`/`SQI`/`LQD`/`SQD`/`ILW`/`ISW`/`ILWR`. Caching `mVU.regs().Mem` in a never-dirty pseudo-VI GPR (`CALIZA_MEM_BASE = 40`) loads it once per block and reuses `[index + base + disp]`. **Verdict: Adopt (implemented).**
4. **microVU1 3-operand AVX FMACs (Forja SX2, app 158)** — Accuracy-preserving. AMD Jaguar supports 128-bit AVX VEX 3-operand instructions (`vaddps`/`vsubps`/`vmulps dst, src1, src2`). Eliminates `vmovaps` clones of `Fs` and `ACC` in `mVU_FMACa`–`d` when `!_XYZW_SS`, `!clampE`, and no operand clamp of `Fs`/`ACC` is needed. **Verdict: Adopt (implemented).**
5. **GS skip dead 64-bit CLUT table expansion (Forja SX2, app 182)** — Accuracy-preserving. Verified repo-wide that nothing in Caliza reads `m_buff64` after `GSClut::Read32`. Skipping `ExpandCLUT64_T32_I8` eliminates 2 KiB of dead writes per 4-bit CLUT reload (~30,000/s in Shadow of the Colossus). **Verdict: Adopt (implemented).**
6. **GS single-pass Gouraud triangle-strip vertex trace (Forja SX2, apps 171–173, hardened)** — Accuracy-preserving. When `iip == 1` and `primclass == GS_TRIANGLE_CLASS`, `GSVertexTraceFMM::FindMinMax` is an associative/commutative reduction over every vertex (handling odd counts cleanly). Deduplicating triangle-strip indices in a single pass cuts `FindMinMax` reads by ~2–3× (Forja measured God of War II `FindMinMax` dropping from 9.3% to 4.5% of GS thread). Hardened in Caliza with a strict strip-invariant bailout so any non-strip or out-of-order index buffer falls back to the original index array with zero risk of missing a vertex. **Verdict: Adopt (implemented).**
7. **GS/Vulkan stability & rendering accuracy fixes (Swordpdf/PS5SX2, `6745ee8`, `effaf73`, `c9f9ee6`+`e3ca17e`)** — Accuracy-preserving crash and corruption fixes: (a) flush queued primitives before `RemoveAll` and clear pending channel-shuffle pointers in `GSRendererHW::Reset` (prevents Neo Geo collection UAF/SIGSEGV); (b) skip `EXTBUF` feedback write in `GSRendererSW::GetFeedbackOutput` when Vulkan SW output is a plain texture (prevents `GetLinkedFramebuffer` abort in Tales of Destiny 2 SW mode); (c) invalidate mip layers 1–6 on host-to-local VRAM writes in `GSTextureCache::InvalidateVideoMem` (fixes Ratchet & Clank 1 stale mip-1 ground ring without breaking repeating sources or GPU draw paths). **Verdict: Adopt (implemented).**
8. **EE `OrbisEEHle` GetThreadId cache invalidation on VM reset & savestate load (Swordpdf/PS5SX2, `cd3da52`)** — Accuracy-preserving correctness fix. Prevents stale cached thread IDs or in-flight exception state from leaking across `cpuReset()` or `PreLoadPrep()`. **Verdict: Adopt (implemented).**
9. **Upstream PCSX2 CPU/VU/FPU accuracy fixes + DEV9/USB hang guards (PCSX2 upstream + Swordpdf `96cd30b`/`a46547c`)** — Accuracy-preserving fixes: microVU `FBRST` reset ordering (`d20a95c`), EE recompiler unaligned 64-bit `LWR` masking (`29ea20f`), VU `vsqrt`/`vrsqrt` flag handling (`1dff55d`), FPU interpreter `RSQRT_S`/`SQRT_S` sign/flag handling (`6d05c7e`), VU0 interpreter `CTC2` `STATUS_FLAG` sticky-only write (`3f682f6`), `Pcsx2Config.cpp` `DNS2` load typo (`a46547c`), USB OHCI 4096-TD loop bound and DEV9 ICMP 20 ms `select` timeout (`96cd30b`). **Verdict: Adopt (implemented).**
10. **High-ROI future engineering candidates (not enabled in this PR)** — (a) `GSDibujoAB` dual-texture A/B draw batching in `tfx.glsl` (Forja apps 167–170; requires `SHADER_CACHE_VERSION` bump and hardware GPU validation); (b) asynchronous/deferred flip thread (`PS4CompleteDeferredFlip` / `ForjaFlipThread`, needs reconciliation with Caliza's `ps4_vk_wsi.cpp` telemetry); (c) `GameIndex.yaml` sync (+75 serials from upstream/Swordpdf); (d) prebuilt CI PS4 SDK artifact (`Phoenixx1202/PS4SX2-SDK` pattern); (e) per-game opt-in speed hacks (`SonidoEnTandas`, `VU1BanderasJustas`, `ForjaIopMaySleep`, `SaltarCuadros` + `ForjaSkipGuard`) strictly behind per-game settings, default off.

## 4. Comprehensive Difference Matrix

Legend for **Speed hack / reduces accuracy?**:
- **No** — Bit-exact or accuracy/stability-improving; safe to enable by default with a `/data/caliza/flags/` off-switch.
- **No (trade-off)** — Does not alter PS2 emulation semantics, but has memory/latency/portability trade-offs requiring hardware tuning.
- **Yes (speed hack)** — Alters PS2 timing, flag semantics, or frame cadence; may break games and must **never** be enabled globally by default (per-game opt-in only, default off).
